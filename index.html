01 // Flagship Substrate

Earthcall

A Person-centered ontology. An engine is attached to it — not the other way around.

“Unlike most of software history, Earthcall is built on a foundational conviction that all beings must be represented not by illusions hiding a teleologically indifferent operating system, but rather according to what they are — their actual, innate structure in reality.” — Earthcall Manifesto

Earthcall is not a game engine with philosophy in the docs. Domain nouns are not C++ classes. A tree is not a Tree. A robot is not a RobotEntity. Beings are authored in-world from primitives every other subsystem can see, then governed by Laws — runtime mathematical rules a Person writes, not hardcoded collisions wearing a story.

The top-level source tree is the ontology: Person, ConstructedBeing, Relation, Singularity, ZonesOfEarth, Identity. Adding a folder is an ontological claim.

People author behavior at runtime. Instead of shipping “move object X to Y,” Earthcall compiles through a Rete-style Law network expressed in OntoMath — one mathematical substrate for geometry, physics, and authored change.

Rendering is a modern WebGPU pipeline with a C++20 substrate, WASM, embedded React/Vite Person surface, and Python foreign IPC.

Substrate Order

  1. Person A human being. Body belongs here. AI is never this.
  2. Ontology Beings, Relations, Formations, Identity, Zones.
  3. Laws Runtime-authored math. First Movers can be switched off.
  4. OntoMath One language for shape, change, collision, telos.
  5. Singularity Ground of the machine: Kernel, channels, permissions.
  6. Vessel C++20 · WebGPU · WASM · React · Python IPC

Load-Bearing Refusals

These are not style rules. They are the architecture.

No Domain Class

No Tree, Vehicle, or hardcoded entity classes. What a thing is is authored in-world.

The Tree is the Ontology

No arbitrary subsystem directories. Foreign hardware/software live under Singularity as channels.

Person Means Human

A Person is an actual human. Generative models are First Movers or Objects; they do not get a Body.

No Black Box

Every field a being carries is a registered property path. Unregistered is ungoverned.

Low-level systems, mathematical rigor, and a refusal to treat people as telemetry units.
