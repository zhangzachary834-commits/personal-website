# Personal Website

A clean, modern personal website built with HTML, CSS, and JavaScript.

## Features

- Fully responsive design (works on mobile, tablet, desktop)
- Modern dark theme with gradient accents
- Smooth scrolling and animations
- Mobile-friendly navigation with hamburger menu
- Projects showcase section
- Skills display
- Contact links
- Easy to customize

## Quick Start

### Option 1: Run Locally (Easiest)

1. Open **Terminal**
2. Navigate to your website folder:
   ```bash
   cd ~/Documents/personal-website
   ```
3. Start a simple server:
   ```bash
   python3 -m http.server 8000
   ```
4. Open your browser and go to: **http://localhost:8000**

That's it! Your website will be running locally.

### Option 2: Open Directly

Just double-click the `index.html` file in your Finder. It'll open in your browser.

## Deploy to the Internet

### GitHub Pages (Free & Easy)

1. Create a GitHub account at [github.com](https://github.com)
2. Create a new repository named `username.github.io` (replace `username` with your GitHub username)
3. Upload all files from this folder to the repository
4. Wait 1-2 minutes, then visit: **https://username.github.io**

### Netlify (Super Easy)

1. Go to [netlify.com](https://netlify.com)
2. Sign up (free account)
3. Drag and drop this entire folder onto the Netlify dashboard
4. Your site will be live instantly with a free URL like `your-site.netlify.app`

### Vercel (Also Super Easy)

1. Go to [vercel.com](https://vercel.com)
2. Sign up (free account)
3. Drag and drop this folder or connect your GitHub
4. Deploy - done!
